# persist-model-roles

Core asks for this host operation by directory name. Native configuration stays in this adapter.

Request: model ids for `xhigh`, `max`, and `fast`. When setup omits ids, use this adapter's defaults.

Write those three roles in Claude Code's own model configuration. Keep the request shape identical to other hosts.
