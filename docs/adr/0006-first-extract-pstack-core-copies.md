# First-extract pstack core copies

First extract copies every `vendor/pstack/` path that rewrites onto today's **host operations** (`spawn-worker`, `persist-model-roles`, `overnight`, `ui-proof`) or that is already host-agnostic after dropping Cursor APIs. Overlay stays same-relative-path, including `skills/poteto-mode/`. Transcript-shaped skills, Cursor-only authoring/eval/session-pickup, Orchestrate, `setup-pstack`, identity files, and `scripts/` stay vendor-only. `setup` and `playbook-runner` are new core files, not overlay pairs.

## Considered Options

- **Copy policy: Grok-rewritable engineering set vs everything that hits today's shims vs a minimal match table (chosen: everything that hits today's shims).** The engineering set omitted overnight playbooks while Grok overnight packaging is still map fog. The overnight shim is already specified (ADR-0004), so autonomous-run, babysit, and the autopilots belong in the first extract. A minimal table (investigation / bug-fix / feature / refactoring / prototype / opening-a-pr) would gut the inherited match table (ADR-0002).
- **Router disk path: keep `skills/poteto-mode` vs `skills/mainart-mode` with an overlay rename vs copy-once `mainart-mode` (chosen: keep `poteto-mode`).** ADR-0001 same-relative-path and ADR-0005 unprefixed upstream directory names already defined this. User-facing slash and display name stay on [Name the router slash command](https://github.com/DavillyDevTeam/mainart-stack/issues/14). Core Skill-tools directory names (ADR-0004).
- **`setup-pstack` vs core `setup` (chosen: vendor-only `setup-pstack`; new `core/skills/setup`).** ADR-0004 already named the core skill. Copying onto `core/skills/setup` would break same-relative-path; copying both would leave two setup skills.
- **Agents (chosen: copy `poteto-agent` and `comment-sicko`; add new `playbook-runner`).** Matches ADR-0002's worker vs in-step split. `playbook-runner` is core-owned, not a vendor pair.
- **`principle-never-block-on-the-human` (chosen: copy all 24; playbook-phase only).** Matt HITL does not Skill-tool it. Dropping it would fork the principle pack; copying with no phase split would leak it into grill-until-empty.
- **Opening a PR `/deslop` (chosen: Skill-tool `unslop`).** `cursor-team-kit` is not in this tree. A `deslop` capability would graduate modules-beyond-Jev fog. Dropping the strip-before-commit gate was rejected.
- **Orchestrate (chosen: vendor-only for first extract).** A Cursor-stripped rewrite (coordinator chat, `spawn-worker` fleets, overnight, no Projects/cloud/control-*) was considered and declined. Later extract stays in fog.
- **Worktree-cleanup (chosen: path-agnostic git worktrees).** `git worktree list` already includes harness paths such as `.grok/worktrees` when they are registered git worktrees. Core must not name host directories. No new host operation.
- **Identity files (chosen: vendor-only `plugin.json`, README, assets).** Host manifests live under `hosts/` (ADR-0004). LICENSE stays on the vendor tree; core ships the Lauren Tan MIT notice with copies.
- **Forge (chosen: `gh` required; `gt` and Bugbot if present; never Origin).** Origin is a Cursor product and stays out. Graphite `gt` is a portable CLI. Bugbot is also a Cursor product; playbooks may invoke it when present and skip when missing (same degrade as an unbound capability). A `review.security` capability was rejected so this extract does not add a second capability beside `validation.judge`.

## Consequences

- A **pstack core copy** is still `core/X` where `vendor/pstack/X` exists and `X` is not a packet-chain path (ADR-0001 / ADR-0005). This ADR names which of those paths exist after first extract. Uncopied vendor paths stay out until a later copy-and-rewrite. Upstream deletions still do not auto-delete core copies.
- **New core files, not overlay pairs:** `core/skills/setup`, `core/agents/playbook-runner.md`. `capability-registry` remains the ADR-0003 gateway.
- **In (rewritten overlay pairs):** `skills/poteto-mode/SKILL.md`; playbooks `investigation`, `bug-fix`, `perf-issue`, `hillclimb`, `runtime-forensics`, `trace-forensics`, `feature`, `refactoring`, `prototype`, `visual-parity`, `pause-safely`, `multi-phase-plan`, `opening-a-pr`, `shipping`, `autonomous-run`, `babysit`, `autopilot-full`, `autopilot-stack`, `worktree-cleanup`; skills `how`, `why`, `architect`, `blast-radius`, `arena`, `swarm`, `interrogate`, `no-comments`, `unslop`, `technical-writing`, `typescript-best-practices`, `benchmark-checklist`, `teach`, `bro`, `ketchup`, `figure-it-out`, `poteto-help`, `correct`; all 24 `principle-*`; `agents/poteto-agent.md`, `agents/comment-sicko.md`.
- **Out (vendor-only), besides paths already forbidden by ADR-0001 / ADR-0005:** `skills/setup-pstack`; `recall`, `reflect`, `automate-me`, `show-me-your-work`, `create-verification-skill`, `maintain-verification-skill`; playbooks `orchestrate`, `session-pickup`, `eval`, `authoring-a-skill`; `skills/poteto-mode/scripts/`; `skills/poteto-mode/references/bugbot-triage.md`; `plugin.json`, `README.md`, `assets/`.
- **Rewrite rules for copies:** Cursor `Task` / `AskQuestion` / `/loop` / host paths become host operations. Overnight-shaped playbooks call `overnight` (`until` or `every`). Opening a PR Skill-tools `unslop`. Swarm/arena call `spawn-worker` from the coordinator session (Grok is depth-1). Visual parity calls `ui-proof`. Worktree-cleanup prunes this repo's git worktrees and names no host directory. Strip `paths` auto-attach from `typescript-best-practices`. Forge steps always use `gh`; use `gt` when present or the repo is a Graphite stack; run Bugbot when present; never Origin.
- ADR-0002's playbook match table is the playbooks in the In list. Investigation stays factual how/why-built.
- This map still does not run the subtree or write a port script.
